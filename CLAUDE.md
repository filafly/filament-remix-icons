# CLAUDE.md

Remix Icon pack for Filament 4 and 5, built on the filafly/filament-icons core.

- `src/RemixIcons.php`: the plugin. `$iconMap` maps every Filament icon alias to a `Remix` case, using the `*Line` case wherever a line/fill pair exists. Keys are alias strings, not `*IconAlias` constants, because some constants only exist in later 4.x releases. `$currentStyle` defaults to Line so style overrides work without a global style.
- `src/Enums/Remix.php`: generated by `php bin/generate-icon-cases.php` from andreiio/blade-remix-icon (Blade prefix `ri`). Don't edit by hand.
- `src/Enums/RemixStyle.php`: Line (`-line`) and Fill (`-fill`).

Commands: `composer test` (PHPUnit + Testbench), `vendor/bin/pint`. The ship gate runs `npm test`, which runs composer update then PHPUnit.

`RemixIconsTest::test_every_filament_alias_is_mapped` fails when a new Filament release adds an alias: map it in `$iconMap`.
