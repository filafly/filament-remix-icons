# Changelog

## v1.0.0 - 2026-11-10

- First release: Remix Icon for every Filament 4 and 5 UI icon alias (223 in Filament 5.11), registered with `RemixIcons::make()`.
- Line (default) and fill styles: `->fill()`, plus per-alias and per-icon style overrides.
- `Remix` enum with all 3,229 icons from andreiio/blade-remix-icon 3.x.
